# Pense-bête juridique – Je lis pour toi

Les pages légales du site sont complètes sur le fond. Il reste à remplir les champs
entre crochets `[À COMPLÉTER]` dès que les informations sont connues.

## 1. Champs à compléter sur le site

| Information | Pages concernées |
|---|---|
| Nom et prénom du ou des porteurs du projet (éditeur tant que l’association n’existe pas) | Mentions légales, Confidentialité |
| Dénomination définitive de l’association | Mentions légales, Confidentialité |
| Adresse du siège social | Mentions légales, Confidentialité |
| Numéro RNA (après déclaration en préfecture) | Mentions légales |
| Numéro SIREN/SIRET (si demandé, par exemple pour recevoir des subventions) | Mentions légales |
| Numéro de téléphone (obligatoire pour une personne morale) | Mentions légales |
| Adresse électronique de contact | Mentions légales, Confidentialité, Cookies (+ page Contact) |
| Directeur ou directrice de la publication (en principe le ou la présidente) | Mentions légales |
| Auteur du logo / de l’illustration | Mentions légales (Crédits) |
| Auteur ou société de production des deux vidéos | Mentions légales (Crédits) |
| Service de messagerie utilisé (Gmail, Proton, Outlook…) et lieu de traitement des données | Confidentialité (§ 4 et 5) |

Après chaque mise à jour, changer la date « Dernière mise à jour » en bas des pages.

## 2. Démarches hors du site (recommandées pour éviter tout litige)

- **Hôpital Necker-Enfants malades (AP-HP)** : obtenir un accord écrit (service de communication
  de l’hôpital et chef de service) pour citer l’hôpital et présenter l’activité dans le service,
  ainsi que pour les vidéos qui mentionnent « Hôpital Necker ».
- **Partenaires (Lions Clubs, Main dans la Main, bibliothèque de Necker)** : leur faire valider
  les textes qui les présentent. Ne pas utiliser leurs logos sans autorisation.
- **Logo et vidéos** : obtenir une autorisation écrite (cession de droits) de leurs auteurs
  pour l’utilisation sur le site et les supports de communication.
- **Couvertures de livres** : usage d’illustration toléré en pratique ; un engagement de retrait
  sur demande figure déjà dans les mentions légales. Pour être tout à fait tranquille, on peut
  demander l’accord des éditeurs (souvent accordé pour ce type de projet).
- **Photos** : ne jamais publier d’image d’un bébé, d’un parent ou d’un soignant sans
  autorisation écrite (et accord de l’hôpital pour toute image prise dans le service).

## 3. À revoir si le site évolue

| Si l’on ajoute… | Il faudra… |
|---|---|
| Un formulaire de contact, d’adhésion ou d’inscription bénévole | Compléter la politique de confidentialité (données, finalité, durée) |
| Un module de dons en ligne | Mentions sur le reçu fiscal, prestataire de paiement, confidentialité |
| Des statistiques de visite (Google Analytics, etc.) | Bandeau de consentement + page Cookies détaillée (ou outil exempté de consentement) |
| Une vidéo YouTube/Vimeo intégrée, une carte Google Maps | Bandeau de consentement ou affichage seulement après clic |
| Un nom de domaine propre | Mettre à jour l’adresse du site (`astro.config.mjs`) et l’hébergeur si nécessaire |

État actuel vérifié (novembre 2026) : aucun cookie, aucun stockage dans le navigateur,
aucune requête vers un service tiers.
